House rules

  • No em dashes anywhere. Plain hyphen, in code and in visible copy
  • No references to AI tools in code or comments
  • Version in the filename and in an HTML comment. Without SSH it is the only

way to confirm what is deployed

  • From-scratch rewrites over patches when a file has accumulated too many

fixes

  • Never open Sitejet in cPanel. It overwrites the site files
  • Nav uses id selectors, never classes. Classes collide with cached CSS
  • display_errors goes after the require, because config.php turns it

off at the bottom

  • No mkdir() in upload handlers. Existing directories only
  • DB_PASS is the MySQL password, not a bcrypt hash

The one concept to understand

ref and boton are separate and must stay separate.

  • ref = where the visitor came from. Set once on arrival, held in the

session. No code means directo

  • boton = what they clicked. Baked into the page, counts without anyone

sharing a link

Merging them destroys attribution permanently. See DECISION 2.

Things that will waste your time if you do not know them

A blank 500 is a syntax error. It happens before display_errors can be turned on. Read /home/lareserv/logs/php.error.log.

Balanced braces are not valid syntax. Run php -l.

"Sesión expirada" on a large upload is not a session problem. The body exceeded post_max_size and PHP discarded $_POST and $_FILES together, so the CSRF token never arrived.

A grid item will not scroll without minmax(0, 1fr) on the row. min-height: 0 alone changes nothing.

A full-width block cannot be centred with margin: auto. It needs width: fit-content.

A relative path in an Exim pipe is not resolved against the home directory. Use $home/pipe_correo.php.

Never rebuild a file from a stale working copy. It happened twice on this project and both times silently removed working features. Check the base file has the functions it should before packaging anything.

A UI label is not evidence of a code path. "media.php uploads 86 MB fine" was filesize() of a file that File Manager had put there. That reading cost an hour.

Verifying a deploy

python3 healthcheck.py

Checks every page, the version markers, the redirects, that the panel is not reachable without a session, and that no diagnostic file is exposed. Exit 0 means clean.
