Si phpMyAdmin responde #1060 Duplicate column name, esa columna ya existia. Se ignora y se sigue.

99-borrar-pruebas.sql

No es una migracion. Es una herramienta de limpieza y borra datos que no se recuperan. Tiene tres bloques y hay que correr uno solo:

  • A mira que hay, no borra nada
  • B borra solo lo de prueba, por direccion de mail
  • C deja todo en cero

Exportar las tablas desde phpMyAdmin antes de correr B o C.
